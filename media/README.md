# 実況解説ショート動画（十字型・4×4）

「ポコっとライト」の実況解説動画（YouTube ショート用・縦長 1080×1920）です。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `poko-light-cross4x4-short.mp4` | 本編動画（1080×1920 / 30fps / 約50秒） |
| `poko-light-cross4x4-short.srt` | 字幕ファイル（YouTube にそのままアップ可） |
| `../scripts/make_video.py` | 動画を生成するスクリプト |

## 動画の構成（約50秒）

1. **イントロ（0〜5秒）** — タイトル「ポコっとライト」とゲーム紹介
2. **どんなゲーム？（5〜12秒）** — 「暗いマスを全部点灯させたらクリア」
3. **十字型のルール（12〜20秒）** — マスを押すと「自分＋上下左右」の5マスが反転
4. **実況クリア（20〜38秒）** — ライトチェイス（暗いマスの“下”を押す）で6手クリア
5. **クリア演出（38〜44秒）** — 全点灯＋紙吹雪＋森の仲間たち
6. **宣伝（44〜50秒）** — 「ボードゲーム広場（boardgamecat.com）で遊べる！」

## ナレーション台本（実況の読み上げ用）

字幕と同じ内容です。声を入れる場合の参考にどうぞ。

- 「はい！今日は “ポコっとライト” を実況解説していきます！」
- 「今回は十字型（プラス型）の4×4。やさしく攻略していきますよ〜」
- 「ルールはかんたん。暗いマスをぜんぶ点灯させたらクリアのライトパズルです」
- 「マスを押すと…押したマスと上下左右、あわせて5マスがパッと切り替わります。これが“十字型”！」
- 「では実況スタート！コツは “ライトチェイス”。暗いマスの “下” を押していくだけなんです」
- 「まず1段目の暗いマス。そのすぐ下を押して…点いた！」
- 「となりも、その下を押す。右はしまで同じようにどんどん送っていきます」
- 「2段目に残った暗いマスも、下を押す。3段目も同じ。光を下の段へ送っていくと…」
- 「最後の1マス！これで…全部ついた〜！クリアです！たった6手！」
- 「このゲーム “ポコっとライト”、十字型のほかにX型・四角型などいろんなパターンで遊べます」
- 「ボードゲーム広場（boardgamecat.com）でプレイできるので、ぜひ遊んでみてね！」

## 動画の再生成

```bash
pip install Pillow imageio-ffmpeg
python3 scripts/make_video.py
```

別のパズル・パターン・盤面で作りたいときは `scripts/make_video.py` の
`PUZZLE` / `PRESSES`（解法手順）や各シーンを編集してください。
パズルとライトチェイス解法は実行時に検証されます。
