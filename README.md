# ライツアウト

Next.js + Tailwind CSS で作ったライツアウトパズルゲームです。

## 遊び方

グリッドのマスをクリックすると、選んだパターンに従って周囲のマスが反転します。全マスを消灯（オフ）にしたらクリア。

## 機能

- **めくりパターン5種類**: プラス型・X型・四角型・同行同列・自分のみ
- **ボードサイズ**: 3×3 / 4×4 / 5×5 / 6×6
- **難易度3段階**: かんたん・ふつう・むずかしい
- **逆算法によるパズル生成**: 解が必ず存在
- **手数カウント・クリアアニメーション**

## 開発

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) で確認できます。

## デプロイ

Vercel に追加設定なしでデプロイできます。
